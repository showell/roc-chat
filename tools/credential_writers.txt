# Every path to a human's credentials, for tools/check_credential_writers.shale,
# whose header has the rules. A `writes` line is a function that writes a file:
# a `credential` or an `other` one, and why. A `calls` line is a call of a
# credential writer: the writer, the caller, the proof that guards it, and why.

writes AccountFiles.replace_password_hash! credential a human's password's hash
writes AccountFiles.create_github_account! credential a GitHub sign-up's account, its github-id among its files
writes AccountFiles.create_github_id! credential the GitHub id that signs in as the human
writes AccountFiles.create_github_session_secret! credential the secret a GitHub session is signed over
writes AccountFiles.replace_github_session_secret! credential the same, written again
writes AccountFiles.replace_session_generation! credential the generation every session is signed over
writes AgentFiles.create_agent_key! credential an agent's key
writes AgentFiles.create_agent_invite! credential an agent's invite, which redeems to a key
writes DeviceCodeFiles.replace_device_code! credential a device code's record, which redeems to a session
writes DeviceKeyFiles.create_device_key! credential the key a device's session is bound to
writes InviteFiles.create_human_invite! credential a human's invite, which redeems to their password
writes HumanInvitesRoute.issue_invite! credential passes a new invite on, for the human its caller names
writes DeviceCodeRoute.make_record! credential passes a new device code on, for the human its caller names
writes SignInFiles.advance_session_generation! credential passes the generation on, for the human its caller names
writes SignInFiles.make_github_session_secret! credential passes the session secret on, for the human its caller names
writes SignInFiles.write_github_link! credential passes a GitHub link on, for the human its caller names
writes DeviceSessionsRoute.sign_out_others! credential passes the sign-out of every other device on, for the human its caller names

calls AgentFiles.create_agent_invite! AgentsRoute.invite_agent! agent-keeper Agents.agent_keeper and Agents.owned_agent: the acting human keeps the agent
calls AgentFiles.create_agent_key! AgentsRoute.redeem_invite! own-code the agent's live invite code, which its keeper made for it
calls DeviceCodeFiles.replace_device_code! DeviceCodeFiles.revoke_live_device_code! revokes it writes the live code cancelled
calls DeviceCodeFiles.replace_device_code! DeviceCodeRoute.make_record! passes-on its callers are judged
calls DeviceCodeFiles.replace_device_code! DeviceCodeRoute.answer_redemption! revokes it writes the redeemed code spent
calls DeviceKeyFiles.create_device_key! DeviceCodeRoute.answer_redemption! own-code a DeviceCode.Redemption, made only from the live code the human's own session made
calls AccountFiles.create_github_account! GitHubSignUpRoute.sign_up! own-github a GitHubSignUp the server signed, of an id GitHub answered that no account holds
calls InviteFiles.create_human_invite! HumanInvitesRoute.issue_invite! passes-on its callers are judged
calls AccountFiles.replace_password_hash! HumanInvitesRoute.join_by_invite! own-code the account's live invite code, made by issue_invite!, whose callers are judged
calls AccountFiles.replace_session_generation! SignInFiles.advance_session_generation! revokes it ends every session but the one its caller signs again
calls AccountFiles.create_github_session_secret! SignInFiles.make_github_session_secret! passes-on its callers are judged
calls AccountFiles.replace_github_session_secret! SignInFiles.write_github_link! passes-on its callers are judged
calls AccountFiles.create_github_id! SignInFiles.write_github_link! passes-on its callers are judged
calls DeviceCodeRoute.make_record! DeviceCodeRoute.make! own-session acting.human_in_session(): a code for the acting human alone, by a full session (FullSessionRoutes)
calls SignInFiles.advance_session_generation! DeviceSessionsRoute.sign_out_others! passes-on its callers are judged
calls DeviceSessionsRoute.sign_out_others! DeviceSessionsRoute.sign_out_other_devices! own-session acting.human_in_session(): the acting human's own devices, by a full session (FullSessionRoutes)
calls HumanInvitesRoute.issue_invite! HumanInvitesRoute.invite_human! new-account the invite of an account HumanInvites.invite makes just now, which holds no credential
calls HumanInvitesRoute.issue_invite! HumanInvitesRoute.invite_human_again! inviter THE OPEN FINDING: a new link for a human who may have joined, shown to the inviter or the admin, whose redemption sets that human's password (docs/design.md, "Sign-in")
calls SignInFiles.make_github_session_secret! SignInRoute.start_session_by_github! own-github a GitHubSignIn.Admission: GitHub answered the id this human's github-id holds
calls SignInFiles.write_github_link! SignInRoute.start_session_by_github_link! own-session a GitHubSignIn.Linked: the human's own session began the trip, they hold no github-id, and no one holds the id

writes AccountFiles.create_account! other an account the server's owner makes, with no credential
writes AccountFiles.create_invited_account! other an invited human's account, its name and inviter, with no credential
writes AccountFiles.replace_account_name! other a human's name
writes AccountFiles.write_name_released! other a lapsed invitee's release of their name
writes AccountFiles.replace_user_counter! other the counter of ids
writes AgentFiles.replace_agent_key_state! other a key's state: only ever revoked
writes AgentFiles.replace_agent_invite_state! other an agent invite's state: spent or revoked
writes DeviceCodeFiles.replace_sign_ins! other the list of a human's device sign-ins, which grants nothing
writes DeviceKeyFiles.revoke_device_key! other a device key's state: only ever revoked
writes DirectoryFiles.replace_channel_members! other a channel's members
writes FileFacts.create_facts_from! other FileFacts' own primitive, which every writer goes through
writes InviteFiles.replace_human_invite_state! other an invite's state: only ever spent
writes JoinedFiles.record_joined! other when a human joined
writes TranscriptFiles.append_message! other a conversation's message
writes TranscriptFiles.replace_reactions! other a message's reactions
writes TranscriptFiles.store_uploaded_image! other an uploaded image
writes TranscriptFiles.replace_upload_total! other a user's upload total
writes TranscriptFiles.replace_last_conversation! other the conversation a user was last in
